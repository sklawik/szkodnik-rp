# szkodnik-rp

This is multiplayer roleplay server project gamemode script for OpenMultiplayer(OpenMP)- a platform that continues San Andreas Multiplayer (SA-MP) legacy.
It was written all by myself back in around 2017-2019 for fun.
It has been now rebooted so it may go live without struggles. 
Educational purposes only.
Please notice, tho OpenMP continues SA-MP legacy it still doesn't have support for security measures as .env or built in reliable Sql database libraries.


[![openmp](https://img.shields.io/badge/openmp-szkodnik--rp-2f2f2f.svg?style=for-the-badge)](https://github.com/Hype02/szkodnik-rp)

Compile:
```bash
./compile.sh
```

Run:
```bash
./run.sh
```

compile & run
```
./compile.sh && ./run.sh
```


deploy on production
```
docker compose build up -d
```
